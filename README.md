# USB_to_UART_converter
-----------------------
USB to UART converter module convert USB data to UART using FT232RL IC.

# Hardware components used
--------------------------
- FT232RL (28 pin package) from FTDI
- 3 pin connector for USB bus power with  selectable external supply so one can select the supply between 3.3V or 5V DC
- Ferrite bead
- 2 smd led for TX and RX data transmission indication
- 6 pin MCU connector
- USB-B (USB TYPE-B) USB 2.0 Receptacle Connector 4 Position Through Hole 
- resistors
- capacitors
